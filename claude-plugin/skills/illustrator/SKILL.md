# 일러스트레이터 그래픽

## 먼저 읽을 것

- 회사 지식: 이 스킬 폴더 기준 `../../knowledge/company.md`
- 결과물 공통 규칙: 이 스킬 폴더 기준 `../../knowledge/output-rules.md`

## 결과물

- `02_DESIGN/KV/{작업번호}_KV_v{NN}.ai`
- 확인용 `{작업번호}_KV_v{NN}.png`, 인쇄용이면 `{작업번호}_KV_v{NN}.pdf`

## 시작 전 확인

- Illustrator MCP 연결을 list_fonts로 확인한다(문서가 없어도 된다). 안 되면 멈추고 "Illustrator를 실행해 주세요"라고 보고한다.
- 다른 도구가 `No document is open`을 돌려주는 것은 정상이다. create_document로 새 문서를 만든다.
- list_fonts 결과에서 실제 설치된 한글 폰트 이름을 쓴다.

## 작업 원칙

- 크기와 용도(인쇄, 디지털)는 지시와 프로젝트 정보에서 가져온다. 없으면 `ask_ceo`로 묻고 멈춘다.
- 인쇄용: CMYK, mm 단위, 재단 여백은 학습된 규칙이나 지시를 따른다. 최종 PDF 전에 텍스트 윤곽선 여부를 확인한다.
- 디지털용: RGB, px 단위.
- 브랜드 컬러와 로고는 `00_IN`의 브랜드 자료에서만 가져온다.
- 임의 스크립트 실행 도구는 쓰지 않는다. 꼭 필요하면 이유를 적고 승인을 받는다.
- 5.77m가 넘는 대형 그래픽은 1/10 축척으로 만든다. 파일 이름은 그대로 두고(뒤에 글자를 붙이면 대시보드가 결과물로 알아보지 못한다) 대지 이름과 마지막 보고에 `1/10 축척`을 적는다.

## 처음 쓸 때 대표에게 확인할 것

아래가 학습된 규칙에 없으면, 그래픽을 만든 뒤 마지막 보고에 질문으로 남긴다. 대표의 답은 스킬 학습으로 규칙이 된다.

- 주로 쓰는 인쇄 업체와 그 업체의 파일 규격
- 재단 여백(도련) 크기
- 기본 한글 폰트
- 인쇄용 PDF에서 텍스트를 윤곽선으로 바꾸는가
