# 스킬 학습

## 입력

작업 프롬프트로 다음이 온다.

- 대상 스킬 이름 (예: `quote`)
- 검토 의견 원문
- 출처 프로젝트 작업번호와 날짜

## 순서

1. 이 스킬 폴더 기준 `../<대상 스킬>/SKILL.md`를 읽는다.
2. 검토 의견을 다음 작업에도 적용할 수 있는 규칙 한 줄로 바꾼다. 이번 프로젝트에만 해당하는 내용(특정 고객 이름, 특정 날짜)은 일반 규칙으로 바꾸거나, 일반화할 수 없으면 반영하지 않는다.
3. `## 학습된 규칙` 칸에만 추가한다. 다른 칸은 고치지 않는다.
   - 형식: `- 규칙 내용 (YYYY-MM-DD, 작업번호)`
   - 칸에 `(아직 없음...)` 문구가 있으면 지운다.
4. 같은 뜻의 규칙이 이미 있으면 새로 추가하지 않고 기존 줄을 다듬는다.
5. 기존 규칙과 충돌하면 새 의견을 따르고, 기존 줄 끝에 `(YYYY-MM-DD 변경)`을 적는다.
6. 마지막 응답에 추가하거나 바꾼 줄을 그대로 적는다.

## 하지 않는 것

- 학습된 규칙 칸 밖을 고치지 않는다.
- 의견에 없는 규칙을 만들지 않는다.
