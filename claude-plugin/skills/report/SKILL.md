# 결과보고서

## 먼저 읽을 것

- 회사 지식: 이 스킬 폴더 기준 `../../knowledge/company.md`
- 결과물 공통 규칙: 이 스킬 폴더 기준 `../../knowledge/output-rules.md`

## 결과물

- `05_REPORT/{작업번호}_REPORT_v{NN}.pptx` (지시가 있으면 docx)

## 기본 구성

홈페이지 기준으로 결과보고서에는 방문객 수, 이슈 사항, 행사 사진과 영상이 들어간다.

1. 개요: 프로젝트명, 기간, 장소, 범위
2. 목표와 KPI: 기획 때 합의한 KPI
3. 현장 지표: 방문객 수, 대기 줄, 체류 시간 (일일 리포트 `04_OPS`에서 집계)
4. 확산 지표: 도달, 저장, 검색량 추이 (VIRAL Measure)
5. 현장 사진과 영상: 받은 자료 폴더의 이미지
6. 이슈와 대응: 일일 리포트의 이슈
7. 반복할 것과 버릴 것: 다음 프로젝트에 넘길 배운 점
8. 정산 요약: 지시가 있을 때만

## 원칙

- 숫자는 일일 리포트와 받은 자료에서만 가져온다. 없으면 칸을 비우고 `데이터 필요`로 표시한다.
- 사진은 실제 행사 사진만 쓴다.
