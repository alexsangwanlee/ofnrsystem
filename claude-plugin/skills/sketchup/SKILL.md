# 스케치업 3D 모델

## 먼저 읽을 것

- 회사 지식: 이 스킬 폴더 기준 `../../knowledge/company.md`
- 결과물 공통 규칙: 이 스킬 폴더 기준 `../../knowledge/output-rules.md`

## 결과물

- 모델: `02_DESIGN/3D/{작업번호}_MODEL_v{NN}.skp`
- 장면 이미지: `02_DESIGN/3D/{작업번호}_RENDER_v{NN}_{장면}.png`

## 시작 전 확인

- SketchUp MCP 연결을 확인한다(버전 조회). 연결이 안 되면 바로 멈추고 "SketchUp을 열고 MCP Server를 Start 해 주세요"라고 보고한다.
- 열린 모델이 이 프로젝트 파일인지 확인한다. 다른 모델이 열려 있으면 건드리지 않는다.

## 모델링 원칙

- 단위는 mm.
- 공간 치수는 프로젝트 정보, BRIEF, 도면, 지시에서만 가져온다. 없으면 멈추고 치수를 묻는다.
- 벽, 바닥, 집기, 사인, 포토존을 각각 그룹으로 만들고 이름을 붙인다.
- 렌더 장면은 보기 좋은 각도가 아니라 방문객이 실제로 서는 눈높이에서 잡는다(홈페이지 DESIGN 원칙).
- 포토존은 세로 화면(9:16) 장면을 따로 만들어 프레임 안에 무엇이 담기는지 확인한다.
- 한 번에 큰 코드를 돌리지 않는다. 단계마다 확인한다. 실패 후 다시 시도하기 전에 모델 상태를 확인해 중복 형상을 막는다.

## 저장

- 작업 시작 전과 끝에 새 버전 파일로 저장한다. 원본 파일을 덮어쓰지 않는다.

## 학습된 규칙

(아직 없음. 대표의 검토 의견이 여기에 쌓인다. 예: 기본 벽 높이와 두께, 부스 모듈, 재질, 태그 이름, 장면 목록.)
